# 演示模式说明

演示模式让你**在没有 Token、不登录、不下单**的情况下体验完整交互流程。

## 启动（不需要任何 Token）

```bash
npm install
npm run build        # 构建后端 + 前端
npm run demo         # 等价于 FORCE_DEMO_MODE=true 启动后端
# 打开 http://127.0.0.1:8787
```

> 不填 `MCD_MCP_TOKEN` 时后端**自动**进入演示模式，无需额外配置。
> 已填 Token 但想强制演示，用 `FORCE_DEMO_MODE=true`（或 `npm run demo`）。

## 演示模式下你会看到什么

| 能力 | 演示模式行为 |
| --- | --- |
| 门店 | 两家虚构门店（演示·阳光店 / 演示·江畔店） |
| 菜单 | 10 个虚构商品，含 2 个套餐 |
| 我的老样子 | 首次启动自动写入 1 个模板 + 2 个版本，可直接体验版本对比 |
| 微调 / 随机 / 食签 | 全部基于上述虚构菜单确定性生成 |
| 能量卡 | 使用虚构营养表，界面标注「演示数据」 |
| 看看优惠 | 使用虚构优惠券，**优惠额为模拟值并明确标注**（真实模式金额一律来自实际核价） |
| 商品图片 | 演示模式没有真实图片，统一显示插画并标注「示意图」，**不与真实图片混用** |
| 核价 / 下单 | 不会调用真实接口；**不产生任何真实订单、不生成支付链接** |

## 演示模式明确不做的事

- 不调用麦当劳 MCP；
- 不写入任何真实订单；
- 不生成支付链接或二维码；
- 不把演示数据标记为真实数据（所有演示来源在界面上都有「演示 / 示意图 / 演示数据」标记）。

## 真实模式需要什么

1. 在 https://open.mcd.cn/mcp 申请 Token；
2. `cp .env.example apps/server/.env`，填入 Token（**不要**加 `Bearer ` 前缀，后端会自动补）；
3. `npm run build && npm start`，打开 http://127.0.0.1:8787。

真实模式下的能力边界与已验证情况，见 [`../MCP_INTEGRATION.md`](../MCP_INTEGRATION.md)。

## 本地数据存在哪、怎么彻底删除

- 默认：`apps/server/data/mcd-old-same.db`（SQLite，含餐单模板、版本、报价、下单尝试、同步的订单缓存）。
- 删除本机全部数据：

```bash
rm -f apps/server/data/mcd-old-same.db*
```

- 数据**只存在你的电脑上**，不上传任何服务器。演示模式的虚构数据同理。
