# 示例数据

> **本目录下的全部内容均为虚构示例，不代表任何真实门店、真实商品、真实价格或真实订单。**
> 用途：演示接口形状、演示自然语言指令写法、演示演示模式的餐单结构。
> 真实模式下本项目不会读取本目录；真实数据一律来自麦当劳 MCP 实时返回。

| 文件 | 说明 |
| --- | --- |
| `demo-meal.json` | 一份虚构餐单（含套餐组成项），用于说明餐品数据结构 |
| `nl-instructions.md` | 自然语言指令示例：本项目支持的“一句话改餐”写法 |
| `mcp-config.md` | MCP 客户端配置说明（指向仓库根目录的 `mcp-config.example.json`） |

注意：示例中的商品编码（如 `MC001`、`FR01`）只在演示库内有效，
**不是**麦当劳官方商品编码，不能用来下单。真实编码来自 `query-meals` / `query-meal-detail`。
