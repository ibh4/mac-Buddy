# 自然语言指令示例

> 以下示例中的商品、门店、金额**全部为虚构**，仅用于说明「一句话改餐」支持的写法。
> 真实使用时，商品名称以你所在门店当前菜单为准。

## 替换

| 你说 | 会做什么 |
| --- | --- |
| 饮料换成美式咖啡 | 在饮料类里找「美式咖啡」替换当前饮料 |
| 薯条换玉米杯 | 小食类替换 |
| 主食别动，其他随便换一个 | 锁定主食，只在其余槽位里换 |
| 中薯条换大薯条 | 同商品不同规格的替换（规格以菜单为准） |

## 数量

| 你说 | 会做什么 |
| --- | --- |
| 再来一份中薯条 | 数量 +1 |
| 薯条少一份 | 数量 -1（减到 0 会移除该项） |
| 可乐两份 | 设为 2 份 |

## 移除

| 你说 | 会做什么 |
| --- | --- |
| 不要薯条了 | 移除该项 |
| 去掉可乐 | 移除该项 |

## 约束

| 你说 | 会做什么 |
| --- | --- |
| 别超过 40 块 | 设置预算上限 |
| 不要香菜 | 加入排除项（**没有**就没有，不硬凑） |
| 主食别动 | 锁定主食类商品 |

## 不会做的事

- **不会**把「不要香菜」理解成「加香菜」；
- **不会**在菜单里找不到某个商品时编造一个近似商品 —— 会直接告诉你「没有找到」；
- **不会**突破你设的预算或锁定，冲突时会说明原因并给出可以放宽哪一项；
- **不会**在你看之前下单。
